## 🎯 Sobre o projeto

**Problema:** O crescimento das apostas virtuais aumenta a exposição de jovens a conteúdos que promovem a ideia de dinheiro fácil e rápido, podendo contribuir para comportamentos financeiros de risco.

**Solução proposta:** O Dobro ou Nada é um jogo educativo desenvolvido em formato de visual novel, que apresenta situações financeiras simuladas por meio de uma história interativa, buscando promover a conscientização sobre os riscos relacionados às apostas virtuais.

**Público-alvo:** Adolescentes e jovens adultos.

**Tecnologias (stack):** Godot, Piskel e demais ferramentas utilizadas no desenvolvimento do projeto.
